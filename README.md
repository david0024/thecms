# thecms

A modern CMS for content sites, built for people coming from WordPress: visual
control, content stored as data, a visual theme builder, isolated modules and
static publishing.

Nothing runs yet. The project starts from its decisions:

- [ADR 0001 — Foundations](docs/adr/0001-foundations.md)
