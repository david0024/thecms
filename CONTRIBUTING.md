# Contributing

- Read [`CLA.md`](CLA.md) first. Opening a pull request means you agree to it.
- Run `bun run check` before you push. It runs the type checks and every test.
- Each change of direction is written down as an ADR in `docs/adr/`.

The core is AGPL-3.0-or-later. Themes, language packs and the client/SDK are
MIT (ADR 0020).
